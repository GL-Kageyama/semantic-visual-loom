# breakdown — ① 把作品切成镜头

**一个镜头为一个变化而存在。** 这是这个基盘的固定方针，而这一段就是执行它的地方。
**按「一个变化」的单位切开作品**，并给每一个切块一个职能。

⚠️ **这不是程序，而是文书。** 它是对会话的指示。**这一段没有代码**——
唯一跑得动的命令是检查器，而它跑的是**这一段写下的记录**。

## 这一段持有什么

| | 什么 | 哪里 |
|---|---|---|
| **作品台账** | `style`・`world.rules`・`world.visual_language`・`constants`・`negative_base` | `projects/<name>/bible.yaml` |
| **连续性的词汇** | `characters:` / `locations:` / `props:`，以及各自的 `states:` | `projects/<name>/ledger.yaml` |
| **镜头序列** | `shot`・`unit.before` / `unit.after`・`role`・顺序 | `projects/<name>/shots/` |
| **开示的变化点** | `disclosure:`——以 `shot` 为键的序列 | `projects/<name>/ledger.yaml` |

**不持有的**——`place` / `time` / `mode` / `motion` / `beats` / `duration` 与两份规格书（**② `design`**），
以及 `reference_set` / `forbidden_set` / `attached` / `disclosure_state`（**③ `ledger`**）。

⚠️ **两本台账是一个文件。** 连续性与开示放在一起持
（`CLAUDE.md` 的「The production ledger is one」）。**不要切成两个。**

## 决定的顺序

⚠️ **这个顺序是设计的主张，检查器并不强制它。** 各层按自己的顺序跑，
`L15`（职能）与 `L24`（模式）**最后、对全项目**跑——它们不是沿途的关卡。
下面是**让下一个需要的东西在需要之前就存在**的顺序。

1. **先作品台账**——`bible.yaml`。`style` 指着 `distill-essence-engine` 里的一张卡，
   `negative_base` 是**作品的禁制**——下游的每一份图像规格都要对这张清单一量。
   **弄错了会响:** `L17`（`bible.style` 为空）・`L21`・`L20`。
2. **连续性的词汇**——`characters:` / `locations:` / `props:` 与各自的 `states:`。
   ⚠️ **这不是凑账，而是让此后的一切都能被指名。**
   `known_keys()`（`check.py`）**只从这里**导出参照的键，而且**`L2` 的消息自己就这么说**——
   把镜头切开，或者在台账里立起这个场所。没有词汇，`place` 就没有可引之处，
   `reference_set` 也没有可引之处。**弄错了会响:** `L8`（台账里没有的参照键）。
   ⚠️ **没有检查会看 `place` 是不是 `locations:` 的键。** 那是**数据的依赖，不是会响的规则**——
   `L2` 只在栏里并排了**多个**场所时才响。
3. **按一个变化切开**——每个镜头写 `unit.before` 与 `unit.after`。
   **弄错了会响:** `L1`（前后相同＝这个镜头什么也没引起）・`L0`（镜头0个）。
4. **同一性从规格那一侧取**——`shot` 是 §19 的 `Instance ID` 去掉末尾 `-<秒>s-<镜次>` 之后的东西。
   ⚠️ **不从 `Segment ID` 取**——同一个区段里有两个拼写，照直导出会掉记录
   （`L13` 以註报告）。**弄错了会响:** `L13`。
5. **给每个镜头一个职能**——从 `rolemap.ROLES` 的**15 种**里取。
   ⚠️ **目録是开着的**——遇到没有的名，**当场定义，并登记**。
   `総覧` / `語り` / `離脱` 就是这样从实测里出来的。**弄错了会响:** `L15`。
6. **写开示的变化点**——`disclosure:`，以 `shot` 为键。
   ⚠️ **只写变化点——不要把每个镜头都排上。** 变化点之间，前一个状态继续。
   **弄错了会响:** `L7a`・`L7b`・`L9`（每一个迁移都与被宣言的位置一致
   ——**一致不是独立性的证据**）。
7. **跑它。**

```bash
python3 engine/ledger/check.py projects/<name>   # 违规与註都要读
python3 engine/ledger/check.py --self-test       # 确认检查器会响
```

## ⚠️ 这一段结束时，仍然红着的

⚠️ **违规 0 件不是这一段的结束条件。** ①和②写的是**同一个成品**，
所以检查器**在中途是红的**——而那是对的。**告诉你这一段失败了不是件数，而是哪些层安静。**

| 结束时应当红着的层，以及它的主人 | |
|---|---|
| `L11`・`L16`・`L17`・`L18`・`L21`・`L22`・`L23`・`L24` | **② `design` 的**——还没有任何东西被演出、被规格化 |
| `L5`・`L6`・`L8`・超出已宣言之点的 `L7a` 与 `L7b` | **③ `ledger` 的**——集合在那里导出 |
| `L25` | **什么也还没生成**——而这一段不生成 |

⚠️ **也要跑 `--self-test`，并读它为何存在。** 它确认检查器会响（**213 例**）。
**什么都不报告的检查，看起来与通过的检查一样**——而把两者分辨开的唯一东西就是自检。

## ⚠️ 没有人读的栏位与规则

⚠️ **把它们写成洞。不要用规则去填。**

- **这一段的输入之形未定。** 作品是以情节来、以剧本来、还是以小说来，
  这个仓库哪里都没写。**与人或会话一起读，并记录你读到的形。**
- **镜头序列没有 schema。** `SCHEMAS` 里的是 `shot-record`，而它**要求 `duration`**——那是②决定的。
  **所以①交不出合法的镜头记录。** 序列就按你自己保有的形保着，并且知道
  **在②落到磁盘之前，检查器什么都不读。**
- **职能的既定模式（`既定モード`）没有人读。** `rolemap.py` 定了它，
  但 `grep 既定モード engine/ledger/*.py` 只返回**定义**，连一条註都没有。
  ⚠️ **所以「职能决定既定模式」是一条没有读者的原则。** 不要发明规则。
  还要注意，**`()` 是「任意」，`None` 是「未定」**——**不要让两者长着同一张脸。**
- **带限定的职能，其正典拼写未定。** `運動（停止）` 引得到，`L15` 以**註**报告它。
  目録里的素名与带限定的拼写，哪一个才是正典**没有决定**——**不要在这里决定。**
  ⚠️ 能加限定的只有 `運動`（`rolemap.QUALIFIABLE`）。
- **谁写台账未定。** 连续性的词汇必须在②写 `place` 与 `time` 之前存在，
  而开示的序列写得晚——所以**如果只能有一段，它会裂在这一段的内部。**
  ⚠️ **记录依赖，但不要决定归属。**
- ⚠️ **职能被宣言为一张卡，实体却是 Python 的字典。** `CLAUDE.md` 定职能
  「作为卡被登记，并生长、精炼」——**目録的实体是 `rolemap.py` 的 `ROLES`**，
  而书式与样式的卡在 `distill-essence-engine` 里，这个仓库**读它，但绝不改写它**。
  **职能的卡，一张也还没有。** 记成洞——**不要在正被读着的目録旁边再加第二本目録。**

## ⚠️ 这里检查器不决定的事

- **那个变化是不是对的变化。** `unit` 是自由文本，`L1` 问的只是归一化之后前后是否相等。
  **配成对，与能检查这一对，是两回事。**
- **那个职能配不配那个镜头。** `L15` 看的是值**引不引得到**，不是对不对。
  没有被用到的职能以**註**报告——**那是作品的性质，不是目録的缺陷。**
- **作品的禁制应当是什么。** `negative_base` 是关于作品的判断。

## 语言

- **`role` 的值是日语。** 它不是交给生成器的字符串（§1–20 里没有它的栏位，
  模型看到的文里一次也不出现）——所以目録里的 `dialogue` 与 `establishing`
  **是给人读的註，不是拼写的一半。**
- **交给生成器的字符串是英语。** 规格、提示词、Negative 都用英语写，**不得翻译**——
  翻译会改变输出。真正咬人的是②，**写在这里是因为 `role` 之所以是例外，理由就在这里。**
- **文书的正典是英语**，镜像并排在同一目录里——见 [`CLAUDE.md`](../../CLAUDE-zh.md)。
