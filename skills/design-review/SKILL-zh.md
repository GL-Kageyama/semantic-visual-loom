# design-review — ①之前的评议会

**设计是最便宜的修改之处，而且没有门。** `check.py` 读的是 `bible` / `ledger` / `shots` /
`specs`；`review` 坐在④之后，打 1–5 分。这个 skill 是**①之前**、只凭设计包运行的门。

## 读什么

作品的设计包——作品计划（`PLAN.md`）与每话一张的设计（`episodes/epNN.md`）——以及它们
指向的原作（故事设计、台帐、镜头表、已采用图像的一览）。**不把散文当散文读。不读镜头。
不读规格。** 它们还不存在，或者属于别的阶段。

⚠️ **读者是下一个会话，不是观众。** 问的不是「观众能否理解」，而是
**「这个设计能切吗、能保住原作吗、能拍吗」**。

## 五个席位

| 席位 | 问题 | 读什么 |
|---|---|---|
| `change` | 每一行都能按一个变化切开吗 | 切分表、`unit`、静止的行、多变化的行 |
| `continuity` | 印记、火、折痕、开示能跨话保持吗 | 计划的连续性规则、各话的开示、原作侧的矛盾 |
| `fidelity` | 设计保住了原作的法则吗 | 故事设计、台帐、草稿 |
| `feasibility` | 能在该路径与已采用图像下拍摄吗 | 路径、样式、参照键、`population` / `body_parts`、时长 |
| `cinematic` | 这个设计承诺了一部电影吗 | 具体的像、摄影机、光、运动、节奏、试播的看点 |

**不要让一个席位代替另一个。** 设计可以忠实却拍不了，可以拍得了却乏味，
可以电影化却不忠实。

## 得分

每个席位返回 **0–100**。作品的得分是**五者平均**。**超过 65 即通过。**

⚠️ **得分是关于设计的判断，不是画面的实测。** 写明读了什么。设计得高分，也可能拍出
乏味的影像——这就是「生成是样本」的意思。

尺度与姊妹评议会相同。有意从严:

| 带 | 含义 |
|---:|---|
| 0–10 | 没有。问题没有被提出 |
| 11–30 | 被点名，但没有运转 |
| 31–50 | 部分。新的执行者被迫猜测 |
| 51–70 | 运转。新的执行者不必猜测就能前进 |
| 71–90 | 稀有。被测量、一贯，例外已宣言 |
| 91–100 | 保留给教科书级的设计。**这一循环不给出** |

**65 是「运转」带的上端。** 不是「一部好电影」，而是「能切、能拍」。
**100 不是目标；实际天花板是 90。**

## 评分标准

每个席位有六项标准。每项按上面的带打分:

| 席位 | 标准 | must |
|---|---|---|
| `change` | C1 所有行已分类; C2 每个多变化行都有指定的切点; C3 `unit.before` / `.after` 能写成差; C4 静止的行选了一个变化或被合并; C5 多变化的集合完整; C6 延后的是数量，不是切点 | C1–C5 |
| `continuity` | C1 印记与火的表成立; C2 折痕的埋设与回收已宣言，含义被保留; C3 开示顺序保持，不提前揭示; C4 原作矛盾以两侧坐标记录; C5 两种火被区分; C6 人物的在与不在、人数跨话成立 | C1–C5 |
| `fidelity` | C1 世界法则七条; C2 视觉禁止; C3 八器官、固定句、四句台词、记忆规则; C4 没有发明的状态、物、规则; C5 不解释应当保留的含义; C6 试播的节拍与草稿和表一致 | C1–C5 |
| `feasibility` | C1 参照键真实存在，或已宣言缺失; C2 路径的要求已决定或宣言; C3 `population` / `body_parts` 已决定或宣言; C4 场所与时刻唯一，记忆不是场所; C5 试播的 key_image 方针与数量已固定; C6 检查器当前的违规被理解并排序 | C1–C5 |
| `cinematic` | C1 每个镜头有具体的像，不是标签; C2 区段形状与记忆时长保持; C3 看点有画面形式; C4 光的语法具体且一贯; C5 运动已决定，或按镜头宣言为洞; C6 声音被当作像来用 | C1–C5 |

`primary_score` 是六项的均值。**只要有一项 must 低于 31，席位封顶 40。**
**均值超过 65，且 must 没有低于 31 时，通过 65。**

## 席位返回什么

```json
{
  "seat": "change",
  "primary_score": 0,
  "critical": false,
  "findings": [
    {
      "where": "episodes/ep03.md:42",
      "what": "一行里装了两个变化",
      "why": "一镜头一变化",
      "fix": "在声音处切开"
    }
  ],
  "note": "2–4 句。读了什么，什么会推动得分。"
}
```

⚠️ **`critical` 只给会改变切分、参照或原作含义的指摘。** 不要把细节缺失标成 critical。
**不要写设计。返回坐标与理由。**

## 循环

1. **只评价试播那一话。** 其他话等到要切的时候再评价。
2. **五个席位独立运行。** 不让一个席位看到另一个席位的返回。
3. **汇总。** 五者平均；列出 critical。
4. **只改设计文档。** 除非作者裁定，不改原作、台帐、图像。
5. **用新的席位重新评价。** 不传递上一次的返回。
6. **平均超过 65，或到 20 回为止。** 记录回数、平均、五个分数、指摘、改了什么。
7. **保留反对。** 作者不采纳的指摘，连同理由保留。不要删除。

⚠️ **低于 65 的一回是结果，不是失败。** 写下是哪个席位拖住了分数。

## 这个 skill 不做什么

- **不改写设计。** 返回坐标与理由；决定的是作者。
- **不与文学评议会混合。** 故事的 13 维平均是另一本台帐；不把这个分数加进去。
- **不给散文打分。** 看的是能否切、能否保住、能否拍、是否承诺电影。
- **不采用。** 采用是选择，作者是编辑。
- **不靠增加席位来平均掉分歧。** 五个席位；有分歧，就写分歧。
