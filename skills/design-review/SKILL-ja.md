# design-review — ①の前の評議会

**設計は、いちばん安く直せる場所である。そして、門が無い。** `check.py` が読むのは
`bible` / `ledger` / `shots` / `specs`。`review` は④の後に座り、1〜5を付ける。
この skill は、**①の前**に、設計書だけで走る門である。

## 何を読むか

作品の設計書——作品計画（`PLAN.md`）と、1話1枚の設計（`episodes/epNN.md`）——
および、それが指す原作（物語の設計・台帳・ショット表・採用済み画像の一覧）。
**散文を散文として読まない。ショットを読まない。仕様を読まない。**
まだ無いか、別の段の対象である。

⚠️ **読み手は次のセッションであって、観客ではない。** 問いは「観客に伝わるか」ではなく、
**「この設計で切れるか・原作を保てるか・撮れるか」**である。

## 五つの席

| 席 | 問い | 読むもの |
|---|---|---|
| `change` | すべての行を、一つの変化で切れるか | 切る表・`unit`・静止の行・複数変化の行 |
| `continuity` | 印・火・折れ目・開示が、話を跨いで保つか | 計画の連続性の規則・各話の開示・原作側の食い違い |
| `fidelity` | 設計が原作の法を保っているか | 物語の設計・台帳・草稿 |
| `feasibility` | 経路と採用済み画像で撮れるか | 経路・様式・参照の鍵・`population` / `body_parts`・尺 |
| `cinematic` | この設計は映画を約束しているか | 具体の像・カメラ・光・運動・リズム・パイロットの見せ場 |

**一つの席に、別の席を兼ねさせない。** 原作を保っていて撮れない設計も、
撮れて退屈な設計も、映画的で不誠実な設計もある。

## 得点

各席が **0〜100** を返す。作品の得点は**五つの平均**。**65を超えたら通す。**

⚠️ **得点は設計についての判断であって、画の実測ではない。** 何を読んだかを書く。
設計が高得点でも、退屈な映像は撮れる——それが「生成は標本」の意味である。

尺度は姉妹の評議会と同じ。意図的に厳しい:

| 帯 | 意味 |
|---:|---|
| 0–10 | 無い。問いが立てられていない |
| 11–30 | 名指したが、動いていない |
| 31–50 | 部分的。新しい実行者は推測を強いられる |
| 51–70 | 動く。新しい実行者が推測せずに進める |
| 71–90 | 稀。測られ、一貫し、例外が宣言されている |
| 91–100 | 教科書級の設計に留保。**このループでは付けない** |

**65は「動く」帯の上端。** 「良い映画」ではなく「切って撮れる」。
**100は目標でない。実際の天井は90。**

## 採点基準

各席に六つの基準がある。それぞれを上の帯で付ける:

| 席 | 基準 | must |
|---|---|---|
| `change` | C1 全行を分類した; C2 複数変化の行すべてに切る点を名指した; C3 `unit.before` / `.after` が差として書ける; C4 静止の行に一つの変化を選ぶか畳んだ; C5 複数変化の集合が完全; C6 延期したのは本数であって、切る点ではない | C1–C5 |
| `continuity` | C1 印と火の表が保つ; C2 折れ目の張りと回収を宣言し、意味を伏せた; C3 開示の順序を保ち、早く明かさない; C4 原作の食い違いを両側の座標つきで記録した; C5 二つの火を区別した; C6 人物の在・不在と人数が話を跨いで保つ | C1–C5 |
| `fidelity` | C1 世界律7; C2 視覚の禁止; C3 八器官・定型句・4つの台詞・記憶の規則; C4 発明した状態・物・規則が無い; C5 伏せる意味を説明していない; C6 パイロットのビートが草稿と表に合う | C1–C5 |
| `feasibility` | C1 参照の鍵が実在するか、欠けを宣言した; C2 経路の要求を決めたか宣言した; C3 `population` / `body_parts` を決めたか宣言した; C4 場所と時刻が一つで、記憶を場所にしていない; C5 パイロットの key_image の方針と枚数を固定した; C6 検査器の現在の違反を理解し、順序を付けた | C1–C5 |
| `cinematic` | C1 各ショットに具体の像がある（名札でない）; C2 区画の形と記憶の尺を保つ; C3 見せ場に画の形がある; C4 光の文法が具体的で一貫する; C5 運動を決めたか、ショットごとに穴として宣言した; C6 音を像として使う | C1–C5 |

`primary_score` は六つの平均。**must が一つでも31未満なら、席は40で頭打ち。**
**平均が65を超え、かつ must が31未満でないとき、65を通す。**

## 席が返すもの

```json
{
  "seat": "change",
  "primary_score": 0,
  "critical": false,
  "findings": [
    {
      "where": "episodes/ep03.md:42",
      "what": "一行に二つの変化が入っている",
      "why": "一ショット一変化",
      "fix": "声の位置で切る"
    }
  ],
  "note": "2〜4文。何を読み、何が得点を動かすか。"
}
```

⚠️ **`critical` は、切れ目・参照・原作の意味を変える指摘だけに付ける。** 細部の欠けを
critical にしない。**設計を書かない。座標と理由を返す。**

## ループ

1. **パイロットの話だけを評価する。** 他の話は、その話を切るときに評価する。
2. **五つの席を独立に走らせる。** 一つの席に、別の席の返答を見せない。
3. **集計する。** 五つの平均。critical を並べる。
4. **設計文書だけを改稿する。** 原作・台帳・画像は、著者の裁定が無い限り動かさない。
5. **新しい席で再評価する。** 前の返答を渡さない。
6. **平均が65を超えるか、20回で止める。** 回・平均・五つの点・指摘・変えたことを記録する。
7. **反対を残す。** 著者が採らなかった指摘は、理由とともに残す。消さない。

⚠️ **65を下回った回は、失敗ではなく結果である。** どの席が足を引いたかを書く。

## この skill がしないこと

- **設計を書き換えない。** 座標と理由を返す。決めるのは著者。
- **文学評議会と混ぜない。** 物語の13次元の平均は別の台帳。この得点を足さない。
- **散文を採点しない。** 切れるか・保つか・撮れるか・映画を約束するかを見る。
- **採用しない。** 採用は選別であり、著者が編集者である。
- **席を増やして、反対を平均で消さない。** 五席。食い違ったら、食い違いを書く。
