# takes/ — この作品のテイク

**このディレクトリに、テイクの記録は1本も無い。** 生成は一度も走っていない。

⚠️ **空を、撮ったことにしない。** ローダーはこの状態を
「`takes/` は在るが、テイクの記録が1本も無い——生成は一度も走っていない」と報告する。
**それは正しい報告である。**

⚠️ **捏造したテイクを置かない。** `adopted: true` は著者の行為であり、
**採用は選別である。** 生成が走るまで、ここは空のままである。

生成が走ったら、`takes/<shot>-video-<n>.yaml` を置く。
盲検 A/B の結果も同じ場所に置く——**どちらが新しい仕様かを隠したまま**、
著者が選び、そののちに正体を開く。
