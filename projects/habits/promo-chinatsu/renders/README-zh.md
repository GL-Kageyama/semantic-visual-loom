# `renders/` —— 作品，以及它所披的声音

> **故事成为一串镜头。** 这里，它成为其中的二十八秒。

`media/` 是标本的场所，这里是作品的场所——与 `projects/hitosara/renders/` 相同的切分。
⚠️ **规则在那边的 README 里。** 这里写的是**此处不同之处**。

## 现在存在的东西

| | |
|---|---|
| `碓氷千夏.mp4` | **无声。** 五个镜头连接而成。**本作的画面正典** |
| `碓氷千夏+bamboo-shadow-waltz.mp4` | 同一画面 ＋ `bamboo-shadow-waltz`。**采用** |

⚠️ **不要写数目**——数目会变动。**试听了八个，制作了四个，采用了一个。**
⚠️ **制作了却未采用的三个，不丢弃，而是指名**——`graphite-in-the-quiet`、
`morning-in-the-hiss`、`chapter-by-lamplight`。**它们存在过，这条记录就这样写。**
⚠️ **它们不在此目录**——这里只有被采用的那一个与无声的画面，
**而选定从外面看就是这个形状。** ⚠️ **选定是作者的**（2026-09-18）。
与 hitosara 同一形状——**四个候选，留下一个。**

⚠️ **`+` 是「画面相同，加了声音」的标记。** 实测——两个文件的视频流与原始文件
**逐字节一致**（`MD5=0f9ea0459665af7a23fe2691f9a67938`，用 `-map 0:v:0 -c copy` 取得）。

## ⚠️ 无声者的声音不是「没有」，而是**空**

`碓氷千夏.mp4` **拥有** `aac` 音轨，48 kHz 立体声。其内容是纯粹的数字静音——
实测 `mean_volume: -91.0 dB` **且** `max_volume: -91.0 dB`，无论整个文件，
还是单独截出第三镜头的区间，都一样。**「没有轨道」与「轨道是空的」不同**——这是后者。

⚠️ **所以音乐并不会混在下面。音乐成为这个文件的声音的全部。**

## ⚠️ 而本作声明了发话——渲染没有承载它

⚠️ **五个镜头中，拥有声音的只有第三镜头，而那是日语**
（`specs/video/shot-03-matter.md`、`bible.language: Japanese`）。渲染的轨道是空的。
**因此，规格所声明的发话，不在本目录的任何文件里。**

⚠️ **这是一个洞，写下来而不填补。** 有两个后果。

- **`+` 不是「带声音的作品」。** 它是**载着音乐的画面**。声音若到来，
  那是要**混在这音乐之下**的东西，而**不能让音乐替换掉它**。
  再替换一次轨道，声音就消失了。
- **看这些文件的人听见音乐，听不见声音**——而且是在一个把「她在说话」本身
  当作设计整体的镜头里。**是否把它当作给人看的版本，是作者的决定，
  不是这条记录的决定。**

## ⚠️ 本作的 Negative 写着 `no background music`

⚠️ **在把这读作矛盾之前，先读那一条的管辖范围。**

`bible.negative_base` 持有基础的三条，`no background music` 是其中之一。
它经由**全部十个规格文件**的 §18 `Negative Prompt` 抵达生成器。
**那一条约束的是生成器。** 作者事后对画面所做的，是另一主体的另一行为，条文不抵达那里。

⚠️ **但在本作中，那一条并未被豁免。** `hitosara` 声明了
`base_negatives_waived: ["no background music"]`——**本作不声明**。
作者 2026-09-18 的决定是：祖父条款只适用于**既有的作品**。
**所以两个作品的差别是实在的，不是疏漏:**

| | 生成器的 Negative | 渲染 |
|---|---|---|
| `hitosara` | **豁免**——条文不抵达 | 载入音乐。**已公开** |
| `promo-chinatsu` | **有效**——十个文件持有它 | 载入音乐。**已采用，未公开** |

⚠️ **把这个给人看的人，正在选择第二行第二列。** 把选择写下来。
**这条记录不替他们决定。**

## ⚠️ 这个目录的空与满，都不被报告

与 `projects/hitosara/renders/` 相同——**没有任何检查读 `renders/`。**
⚠️ **不报告的检查，看起来与通过的检查一样。** 所以这张表是**只有人才能读的记录**，
