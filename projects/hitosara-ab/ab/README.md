# 盲検 A/B — `s08` の1本（**プロンプトの水準**）

**このショットの値を転換する1本で、`## DIRECTION` が「より劇的に読まれるか」だけを測る。**

⚠️ **この組が測ったのは仕様であって、映像ではない。** 生成は1本も走っていない。
何を測れて、何を測れていないかは、末尾の「⚠️ の限界」に全部書く——
**そこを読まずにこの表だけを持ち出すと、測っていないものを測ったことになる。**

⚠️ **1組の結果は証拠ではない——証拠は組数である。**

## 手順（実際にやったこと）

1. 2本の仕様から、生成器に渡る**七つのスロットだけ**を取り出した。
   `DIRECTION` は節ではなく、**Master Prompt の先頭段落**として入る——
   生成器はこの形で受け取る。→ [`packets/A.txt`](packets/A.txt) / [`packets/B.txt`](packets/B.txt)
2. **無作為に A / B を振った。** A が新、B が旧になった。
   → [`packets/codebook.txt`](packets/codebook.txt)
3. **四人の評価者**（`emotional-impact` / `aesthetic-critic` / `admiration` / `hook`）に、
   **A と B の両方を全文、A / B のラベルだけで渡した。** ファイルにも `codebook.txt` にも
   触らせていない。「どちらが新しいか」も「何が違うか」も言っていない。
4. 各評価者に、**自分の次元**で 1–5 を付けさせ、「どちらを推すか」と理由を1–2行で書かせた。
   ⚠️ **「仕様に忠実なのはどちらか」では選ばせていない。** それは `L11`–`L47` の仕事である。
   **ここで測るのは、届いたかどうかである。**
5. **四人の答えが揃ってから** `codebook.txt` を開いた。

### 四人が同じことを言った

**理由の語彙が、四人でほぼ同じだった。** これは独立した四つの証言ではなく、
**同じ一つの読みを四回聞いた**可能性が高い（限界を参照）。それでも、何が効いたかは一致している:

- **意図の名前。** `Play discover, not surprise.`——「驚き」ではなく「発見」として演じろ、
  という一行が、残り全部の抑制を**消極ではなく積極**に変える。
- **値の転換。** `sealed` → `open` と、**賭け金**（一晩が無駄になったかどうか）が名指される。
  旧は同じ変化を持っているが、**値として名指していない。**
- **反・誇張。** `Do not ask the fire to perform for us`——これが無いと、
  生成器は沈黙を**自前の既定**（＝より多く）で埋める。四人とも、この危険を名指した。
- **終わりの画。** `End on a single mote of flour burning`——最後の一枚が固定される。

⚠️ **`hook` だけ低い（3 と 2）。** この1本は**閉じる所作**であり、
`DIRECTION` が `the dark above it` で**枠を閉じる**からである——
「続きが気になる」次元は、この1本が負う値ではない。**次元によって効き方が違う、という測定値である。**

## ⚠️ の限界——**ここを読まずに表だけを持ち出さない**

1. **映像は1本も生成していない。** 測ったのは「四つの言語モデルが二つのテキストをどう読むか」であって、
   **「映像生成器がどう作るか」ではない。** この計画が知りたいのは後者である。
   **この表は、その手前の一枚にすぎない。**
2. **評価者は独立した観客ではない。** 四人は同じモデル系の評価エージェントで、
   **作者の道具と同じ家系**にいる。人間の観客の代理ではない。
3. **n = 1 組、評価者 4 人。** 組数を増やさない限り、これは**事例**であって**証拠**ではない。
4. **交絡がある。** `DIRECTION` は**見るからに「演出の注記」**である。
   評価者は「より意図的に書かれた方」を高く読んだかもしれない——
   つまりこれは、**「演出の散文が加わると、より意図的に読まれる」**を測った可能性がある。
   「より良い映像になる」を測ってはいない。
5. **生成器が受け取る形とは厳密には違う。** 評価者は両方を全文読んだが、
   生成器は七つの欄を別々に受け取り、**互いの欄を参照しない。**
   `DIRECTION` が Master の先頭で効くかは、**実際に走らせないと分からない。**

---

## 次に何が要るか

**同じ2本を、同じ経路・同じ尺・同じキー画像で生成し、盲検にかける。**
そのとき初めて、「映像が劇的になったか」を測れる。
この組はその**予備**であり、**予備を本試験と呼ばない。**

⚠️ **採用はここでは決めない。** 採用は `takes/` に著者が書く行為である——
**A/B は選別の材料であって、選別そのものではない。**
そして **4 / 4 は、採用の理由にならない。** 評価者が四人とも同じ家系にいる以上、
この一致は**著者の判断を代行しない。**
