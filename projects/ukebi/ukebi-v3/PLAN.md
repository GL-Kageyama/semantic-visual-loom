## 0. 先に決めたこと（聞かずに決めた。理由を添える）

### 0-a 可能か——**枠は在る。素材は足りる。そのままでは撮れない穴が三つある**

**枠は在る。** `projects/ukebi/ukebi-v3/` に README と `episodes/` の10枠がある。
`bible.yaml` / `ledger.yaml` / `shots/` / `specs/` はまだ無い。
いま検査器を回すと、**違反6件・註32件**——内訳は L0 が3件（ショット0・台帳が空・disclosure が空）、
L14（§18 を1本も読めない）、L27（言語未宣言）、S0（`jsonschema` が無い）。
**これは欠陥ではない。** 検査器が「まだ何も見ていない」と言っている。
**空の検査は OK と言う**——だから、この6件を緑として読まない。

**素材は足りる。** sVL の三層に、原作がすでに対応している。

| sVL の層 | 原作の置き場 | 状態 |
|---|---|---|
| ① 作品台帳（不変の世界） | `構想/design.md`「世界律」7・「視覚の規則」・「禁止」 | 書かれている |
| ① 制作台帳（連続性と開示） | `台帳/`（人物8・舞台装置8）＋`design.md`「開示の順序」 | 書かれている |
| ② 演出（§1–20） | `草稿/ショット表_*.md` 10本（222行） | 行はある。ショットではない（0-d） |
| ③ 参照集合 | `distill` の31枚 | 31枚とも採用済み |

**穴が三つある。** どれも設計で閉じる。閉じずに撮ると、同じ穴を20本ぶん掘る。

1. **`one-lamp-cel` に `## Motion character` が無い。** 実測: distill の様式カード3枚のうち、
   持つのは `soft-cel-anime` だけ。`L20` は「`Style Motion` は在るが空」と鳴る（0-g）。
2. **踏切の採用済みの板は、台帳と三箇所食い違う。** 舗装・無地の腕木・消灯した灯（0-j）。
   この板を location の `base` に据えると、食い違いが全ショットへ配られる。
3. **枠の数が古い。** 「195ショット」は S だけで、表は222行（0-d）。「26枚」は11-15より前の数で、
   いまは31枚。自己検査は「510/515」ではなく **508/513**（実測）。

### 0-b ディレクトリ＝**1作品。話ごとに分けるのは設計書だけ**

**作品を10に割らない。** `projects/ukebi/ukebi-v3/` のまま、`bible.yaml` / `ledger.yaml` /
`shots/` / `specs/` を1組だけ持つ。話ごとに分けるのは **`episodes/epNN.md`（設計書）** だけ。

理由は四つ。

1. **検査器は再帰しない。** `check.py` は `root/shots/*.yaml` を平らな glob で読む。
   作品が作品を持つと、親を回しても読まれず、**出力もそれを言わない**（`L29`）。
2. **台帳は作品に1つ。** 10に割れば、同じ `bible.yaml` / `ledger.yaml` を10部コピーすることになる。
   **写しは黙ってずれる。**
3. **開示は話を跨ぐ。** 第3話の折れ目は第9話で意味が通る。第1話の喉の留まりは第4話で花になる。
   話ごとに割ると、第3話の台帳は第9話を知らない。
4. **参照は共有。** 送り火の設定画は10話すべてに効く。31枚を10箇所へ配れば、また写しが増える。

**話の名前は ID に入れる。** ショット ID は `ukebi-ep03-s01` の形。
**話は束ねるための目盛りであって、作品の境界ではない。**

### 0-c 範囲＝**第3話「綴じる」をパイロットにする**（20行＝S16＋M4、7分）

**第1話ではない。** 第1話の二人称POVと八器官の通しは、この作品で一度きりだ（二人称は第10話にも出るが、
八器官を全部通すのは第1話だけ）。**繰り返す機構を試さないパイロットは、パイロットでない。**
第1話は「入口」の試験であって、「制度」の試験ではない。

**第3話で試すもの**——どれも第3〜9話で繰り返す。

| 試すもの | なぜ第3話か |
|---|---|
| 記憶（M4本） | 記憶は8話のうち7話に在る（第1・6・10話を除く）。**火の中の像**は、この作品で最も特殊な規則 |
| ゲストの同一性 | フミ。設定画1枚から、火の中の人物を固定できるか |
| 物（台帳） | 白頁・焦げ跡・折れ目。**物が話をまたいで状態を変える**唯一の例 |
| 戻らない形 | 折れ目は第9話の回収。**説明せずに形だけ置く**試験 |
| 長い行 | 36秒（M01）。**一行が一ショットかを試す**のに十分な長さ |

**第10話ではない。** 35行・10分・二人・白頁・六つの跡。大きすぎる。
**第2話ではない。** 試作で裁定済み（`草稿/第2話_送る_試作.md`）。型の確認には良いが、
改稿の山は第3話にある（`episodes/ep03.md`「改稿」）。

### 0-d 単位＝**行はショットではない。変化で切る**

**表は222行である。** 内訳は S 195行＋M 27行（実測）。
**「195ショット」は S だけを数えた数**——`episodes/index.md` の旧「ショット」列も同じ数え方だった
（いまは「行（S＋M）」に直した）。
しかし `草稿/README.md` は M も「M ショット」と呼ぶ。**sVL では M もショットである**
（尺と変化を持つ。生成1回ぶん）。ゆえに**出発点は222行**。

**尺の実測**（222行、`画面` 欄の範囲から）:

| | |
|---|---|
| 合計 | **4,260秒＝71分00秒**（設計の「約71分」と一致） |
| 平均 | 19.2秒 |
| 中央 | 18.0秒 |
| 最短／最長 | 4秒／40秒 |
| 話ごとの平均 | 14.3〜22.1秒 |

sVL の記録にあるショットの `duration` は **2〜14秒**（127本、最頻8秒が16本）。
**これは違反ではない。** 尺は従属変数だ。切る理由は「一つ変化」だけであって、尺ではない。
ただし**30秒を超える行が3本ある**（第3話 M01＝36秒、第7話 M01＝40秒、第8話 M01＝40秒）。
V2 は WAN 3.0 で30秒を回した。**この3本は、切るか、尺を30秒以下に置くか、経路の上限を確かめる。**

**既知の複数変化。** 第1話の八器官は、4行に8つ入っている——
S12（手・指）・S13（喉）・S14（腕・耳・目）・S15（声・背）。
第1話を撮るときは、**この4行が8本以上になる。** 第3話にはこの形は無い。

**静止の行は、変化を持たない。** 例: 第3話 S01「踏切。上がったままの遮断機。濡れた砂利。」——
名詞が三つ並ぶだけで、何も変わっていない。`L1` は `unit.before` と `unit.after` が同じなら鳴る。
**静止の行には、光・空気・水面・カメラのどれかで変化を取る**
（固定方針の「一つのカメラ事象」も変化である）。取れなければ隣の行へ畳む。

**本数は切った後に数える。** いま書けば、それは予測であって実測になる。
**ただし、切る点は延期しない。** パイロット（第3話）は [`episodes/ep03.md`](episodes/ep03.md) で
**28本**に切った——切る点・`before`/`after`・人数・key_image まで決めた。
**数える延期と、切る延期は違う。** 他の話も、切る点を決めてから本数を数える。

### 0-e 場所＝**踏切ひとつ。記憶は場所ではない**

台帳 `舞台装置/踏切.md` が二つを固定している。

- 「唯一の舞台。全話の現在はここ。**カメラはこの場所を出ない。**」
- 「**記憶のあいだも、画面の縁に踏切の板か水たまりを残す。**」

ゆえに**全ショットの `place` は `踏切`**。
記憶の内部（机・部屋・戸口・夜の野・雨の踏切）は `locations` に立てない。
それは `記憶` の `appearance` と §9 が持つ。**場所を一つにすることで、`L2` は構造的に鳴らない。**

これは退屈ではなく、この作品の法だ。`locations` の鍵が一つであることは、
`migenzo` の「一室」と同じ形である。

**第10話の白頁は、場所の状態にしない。** 台帳「第10話だけ、カメラが少し上がる。最後に白くなる」。
白は**画面の事象（頁）**であって、踏切の状態でも新しい場所でもない（design）。
`踏切.states.白頁` は置かない。`place` は `踏切` のまま、§9／§13 と `unit` が
「画面が白くなる」を持つ。**`locations` を増やさない。**
⚠️ 第3話の初頁の白（`初頁.白`）と、第10話の白頁は別のもの。名前を混ぜない。

### 0-f 時刻＝**時刻を持たない**

design「境に朝はない」／台帳「太陽も月も星も無い」。**境の明るさは火だけが作る。**
全ショットの `time` は `時刻を持たない`。既存作にも同じ値がある（13本）。

記憶の内部の時刻は**ビートに置く**。`L3` はビート本文の時刻語が3種以上なら鳴る。
一つの事件なら3種にならない——なるなら、その行は二つの事件を持っている。

### 0-g 様式＝**`one-lamp-cel`。ただし `Motion character` が無い**

このカードは**この作品から作られた**。カードの Examples が
「受け火 → art board, the boundary crossing」と名指している。
「光はひとつ・bloom 無し・flare 無し・二次光源無し」は、design の光の規則そのものだ。

**しかしカードに `## Motion character` が無い**（実測）。`L20` は
「`Style Motion` は在るが空である」と鳴る。道は二つ。

1. **distill のカードに `Motion character` を足す**（推奨）。ただし**カードは distill の持ち物**だ。
   sVL からは書かない。著者の裁定が要る。書くなら、この作品の運動はこうだ——
   「限定アニメーション。止めと送り。指・まぶた・息だけが動く。カメラは低く、ほぼ動かない。
   火だけが揺れる。モーションブラーもスピード線も無し。」
2. **空のまま、理由を記録する**（design skill が許す）。71分の作品で、様式が運動を何も言わないのは重い。
   **穴として記録し、`L20` を承知で残す。**

`soft-cel-anime` へ替える案は採らない。あのカードは bloom と haze を要求し、
design の「bloom も lens flare も無し」と正面から衝突する。

⚠️ **`SVL_STYLES_DIR` を distill の `references/styles/` へ張る。**
張らなければ `one-lamp-cel` は読めず、`L20` は「確かめられない」と註で言う。

### 0-h 経路＝**WAN 3.0。1ショット1枚の `key_image` を持つ**

- V2 は WAN 3.0・30秒。改稿の行は4〜40秒。**30秒を超える行が3本ある**（0-d）。そこは切るか置く。
- H3 の利点（1ショットが複数場所を持つ）は、この作品では使わない。**場所は一つだから。**
- SEEDANCE 2.5 は `Negative Prompt` を床として受け取らない（字幕と音声の否定だけ効く。`L30`）。
  この作品は禁制が多い（文字・群衆・光・雨）。向かない。
- WAN は `key_image` を添付する経路。**ゆえにパイロットは、切った本数ぶんの `key_image` を作る。**
  本数は切った後に数える。既存31枚は参照に回す。

**画像は二段で作る**（distill の「一貫性は二段で作る」と同じ）。

1. **設定画（`soft-cel-anime`）で顔を固定する。** 人物が写る画は、その人物の採用済み設定画を参照に渡す。
2. **`key_image`（`one-lamp-cel`）で光と構図を決める。** 参照は顔を固定する。光・構図・様式は本文が持つ。
3. **動画（WAN・`one-lamp-cel`）へ渡す。** 設定画を直接渡さない——`key_image` が様式を運ぶ。

### 0-i 人数＝**0・1・2。ゲストは踏切では火**

**踏切に立つ体は、送り火と花だけ。** ゲストは火であり、体を持つのは記憶の中だけだ
（design「記憶の中の人物も、その話のゲスト1人だけ」）。

実測: 第5話は 送り火＋花＋コダマの火＝**2体**（`draft_05`「彼女は、彼の腕からコダマの火をそっと下ろす」
「彼を膝の上へ下ろす」——膝の上に載るのは送り火で、コダマは火のまま）。
第10話も2体。第1話は送り火1体＋視聴者の足元。**design の禁止「三人以上の人」と一致する。**

`population` は**同時に見える最大数**。0（火だけ・POVで足元を映さない）／1／2。
足元のPOV（第1話 S02・S19）は **1＋`body_parts: {foot: 2}`**（足は一つの体の一部。L52）。
足元を映さないPOVは 0。手だけの画は `{hand: 2}`。**人数は体を数える**——部位は別に宣言する。
POVの足元は、`characters` に `あなた` を立てる（参照画像なし、足だけ）。`cast: [あなた]`。

**記憶の影は人として数えない。** 影は光の落ち影として書く。
ただし**生成が体を出したら、`population` を2へ直す**。直したことは記録に残す。

### 0-j 参照画像＝**31枚のうち、14枚を参照に、10枚を key_image に、7枚をどちらにも使わない**

| 用途 | 枚 | 中身 | 行き先 |
|---|---:|---|---|
| 参照 | 10 | 人物の設定画8＋立ち絵2（送り火・花） | 設定画は `characters.<名>.identity`。**立ち絵は話ごとの候補**——火を持つので、火の大きさを先に決めてしまう。第6話は使わない |
| 参照 | 4 | 台帳・秤・判・記憶 | `props.<名>.appearance` |
| key_image | 10 | 場面の板 ep01〜ep10 | その場面の1〜2本 |
| 使わない | 2 | 所作の板（八器官・花の五つの動詞） | 多姿勢。参照にすると複数を描く |
| 使わない | 4 | キービジュアル・表紙・ポスター・サムネイル | `package` の売り物 |
| 使わない | 1 | 踏切の板（`art-board-crossing`） | **台帳と三箇所食い違う**（下） |

⚠️ **場面 ep07・ep08 の板は、炎が胡桃**（`採用表` #30・#31）。第6話は小豆で、第5話の胡桃から縮む段の続きだから、
**第7・8話でそのまま key_image に使うと火が大きくなる**（`魂火.md` の「少しずつ縮む」に反する）。
第7・8話は板を使わないか、小豆以下で焼き直す。

**踏切の板は載せない。** 台帳と食い違う三箇所は、舗装（台帳は砂利と土）・
無地の腕木（台帳は白黒の帯）・消灯した灯（台帳は灯なし）。
distill は「この板だけ例外として残す」と裁定したが、**sVL では例外にできない**——
据えれば全ショットがこの板を引き、食い違いを配る。
**location の `base` は、補正済みの板を新しく焼くまで「意図」として置く**
（hakuchizu の `通り.base` と同じ形。「まだ無い。意図であって資産ではない」）。

**火は二つある。名前を一つに固定する。**

- **ゲストの火**＝送られる火。ゲストの魂。踏切では小さい火。ゲストの `identity` が持つ。
- **魂火**＝残る側の火。唯一の光源。彼の掌の上。話ごとに小さい。`props.魂火` が持つ。
- **ゲストの火は、場を照らさない**（第2・4・5話）。⚠️ **第1話は「遠い光」でレールの錆と水滴が見える**と書く——例外として両座標で記録する（`ep01` と `ep02/04/05`）。

⚠️ 台帳は両方を「魂火」と呼ぶ箇所がある（第2話「ゲストの魂火」）。この作品では
**残る側を「魂火」、送られる側を「ゲストの火」**と固定する。「残る火」は source に無い仮の語なので、本文では「魂火」と書く。

**パイロット（第3話）の key_image は28添付・27新規。** 再利用は0。
折れ目の寄りを2枚新規（s11／s12・s13 共有）、残り25本を新規（s09 の白頁・s14b の半ば閉じた台帳を含む）。
**新規に焼くのは27枚。** 1ショット1枚（s12/s13 は同じ画像を共有）。**枚数は切った後に数えた結果である。**
**採用済みの場面 ep03 は、折れ目が讀めず、初頁にペン先の跡がある——s09 にも s14b にも使わない。**

**ゲストの4面設定画は、key_image の参照に使う。** 動画へ直接渡さない——key_image が顔を運ぶ。
**踏切の location 画像は、パイロットでは使わない。** `base` は意図だけ。地理は文、
見た目は各 key_image が作る。補正済みの板はポストパイロットの資産。

⚠️ **著者承認の台帳修正は、まだ台帳へ入っていない**——折れ目の一行（`台帳.md`）・記憶の M行2:06（`記憶.md`）・花の登場の「1」（`README.md`）。**写しの段で落ちるので、著者が入れるまで値は設計側にしかない。**

**台帳の印と火の段は、話ごとの表として `bible.constants` に置く。**
sVL の `props` には `states` が無い——印も火の大きさも「物の状態」だが、宣言する場所が無い。
だから表を作品定数に置き、各ショットの §5／§15 がその話の行を読む。
**状態機械にしない。** この作品の変化は話ごとに決まっている（design の表）。

### 0-k 文字と音＝**文字なし、声のみ、BGM なし**

- design「画面に読める文字を置かない」。台帳・秤・判・頁・標識のすべてに字が無い。
- 文字は生成しない。字幕も出さない（`L21` の床）。
- 声: 定型句9回（第1〜9話の末尾）・花の台詞4・「該当なし。」1・ゲストの名・第2話の火の問い。

## 2. 話ごとの設計の置き場

**1話1枚。`episodes/epNN.md`。** 枠（正・改稿・参照・未決）を残したまま、設計を足す。

## 3. 手順

1. **`bible.yaml`**——`design.md` の世界律7・視覚の規則・禁止から。
   - `bible.style: one-lamp-cel`（0-g の裁定待ち）
   - `bible.language: Japanese`（値は英語）
   - `bible.world.rules`: 7律（送ることは受け取られることに先立たれる／文字は保たない／名は声にしかない／
     記憶は火の中／光は魂火ひとつ／死んだ者は一つの語で呼ばれる／送る者は決して受け取られない）
   - `bible.constants`: 八器官・火の段（話ごとの表）・印（話ごとの表）・カメラは踏切を出ない・文字なし
   - `bible.constants.video`: **映像の四定数**——`aspect: 16:9` / `resolution: 1920x1080` /
     `frame_rate: 24fps` / `orientation: Landscape`（`specmap.VIDEO_CONSTANTS`・L26。**L26 は大小を区別する**——既存作の綴りに合わせる）
   - `bible.negative_base`: design の禁止を**英語で**。文字・群衆・雨・太陽月星・bloom/flare・
     二次光源・BGM・字幕・3D・写実
   - `bible.song` は**置かない**（0-k）
2. **`ledger.yaml`**——`台帳/` の写し。
   - `characters`: 8。`identity` は設定画を名指し、`negatives` は台帳の禁止から。
   - `locations`: `踏切` 1つ。`base` は補正済みの板の**意図**（0-j）。`geography` は台帳の形・カメラ・音。
   - `props`: `台帳`・`秤`・`判`・`記憶`・`魂火`・`手紙`。`appearance` と `negative`。
   - `disclosure`: 全話の変化点。話ごとの設計書から集める。全ショットを並べない。
     **第2話の S16、第3話の S09/S11、第7話の S15a、第8話の S14、第9話の S13 は `form_only: true` を付ける**（開示でなく伏線）。
3. **パイロット（第3話）の breakdown**——20行を変化で切る（`episodes/ep03.md`）。
   `unit` / `role` / `place` / `time` / `mode` / `motion` / `beats` / `duration` /
   `population` / `body_parts` / `cast` を埋める。
4. **§1–20 と §18 の7スロット**——`L16`（motion）・`L17`（slot）・`L21`（BGM/字幕）・
   `L38`（演出要約）・`L6`（attached）・**`L51`／`L52`**（`population` と `body_parts` の英語2文と、
   その Negative 側の写し）の形を**先に**通す。`L20` は 0-g の裁定で決まる。
5. **画像仕様（`key_image`）**——**画像の経路は `CHATGPT IMAGE 2.5`**（Prompt と Negative を一つの節の2段落として保ち、空行で繋ぐ）。**WAN は動画の経路**——key_image は WAN で焼かない。既存の場面の板は、合う1本にだけ使う。
6. **`ledger` の導出**——`reference_set` / `forbidden_set` / `attached`。
   **参照画像の実ファイルを指す。** `attached` は宣言であって記録ではない。
7. **`check.py` がゼロ（または記録した保留）になるまで。** ⚠️ **L20 は除外の席が無い**——
   `one-lamp-cel` に `## Motion character` が無いため、**L20 の1件は残る**。これを**設計の記録で保留**とし、
   「ゼロ」ではなく「**L20 の保留1件**」を終了条件に書く。カードを直すのは著者（distill の持ち物）。

   それから画像→全部見る→動画。
8. **生成は最後。** 選別は著者。生成物は採用候補であって作品ではない。
