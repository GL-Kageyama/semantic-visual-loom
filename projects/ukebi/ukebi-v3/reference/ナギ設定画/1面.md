# ナギ設定画の1面 — 切り抜き

**2026-11-17。** 第8話の記憶の基準を燒く前に、4面の設定画を1面にする。

## 0. 出所

- 元の繪: `distill-essence-engine/examples/works/novels/ukebi-anime/ukebi-anime-character-sheet-ナギ/戦時風アニメ青年キャラクター設定画.png`（2026-11-14 採用、1672×941）。
- 出力: `reference/ナギ設定画/1面.png`（300×600）。
- **燒き直しではない。** 採用済みの4面から正面を切り抜いただけである。顏・髮・帽・外套・姿勢は元の繪のまま。

## 1. 切り抜きの範圍

| | 畫素 |
|---|---|
| 左上の x | 170 |
| 左上の y | 0 |
| 幅 | 300 |
| 高さ | 600 |

上段の四つの向きのうち、**正面（左端）だけ**。白地の余白を左右に殘し、隣の斜めの像と下段の表情の頭を入れない。

## 2. 何が入り、何が落ちたか

**入る**: 正面の全身。帽・顏・首・外套・褲・靴。片方の頬の土。胸の內側の紙は見えない（元の繪でも見えない）。

**落ちる**: 斜め・橫・後ろの三面。表情の頭四つ。紙のインセット、頬のインセット、帽の鍔と目のインセット。

⚠️ **記憶の畫には正面の1面で足りる。** 4面のまま添えると、モデルが四人を描く——`手焼き基準.md` の順7が止まっていた理由である。

## 3. 檢品

- 像が一人だけか。隣の像の肩・腕が入っていないか。
- 下段の表情の頭が入っていないか（下端）。
- 帽・外套・ズボン・靴が切れていないか。
- 顔が正面か。目が閉じていないか。
- 白地か。文字・記章・武器が無いか。

## 4. 使うところ

- 第8話の `ナギ.identity` を取る仕様（m01a〜m04 の9本）。
- ⚠️ **`ナギ.states.火`（外套の形の火）はこの畫を使わない。** s02〜s05・s07。火の形は `reference/火.md` §4 の `one coat-shaped pale fire` / `the shape of a soldier's coat`。畫像ではなく block。
