# 第3話の画像仕様と生成物

**1ショット1フォルダ。** 仕様と生成物が同じフォルダに同居する。

- `ukebi-v3-ep03-<連番>-<ラベル>/` — 置き場。
  - `ukebi-v3-ep03-<連番>-<ラベル>.md` — 画像仕様。
  - 生成物 — **名前を変えずに**このフォルダへ置く。
- 例: `ukebi-v3-ep03-01-s01/ukebi-v3-ep03-01-s01.md` と
  `ukebi-v3-ep03-01-s01/夜霧に沈む踏切の線路.png`。

⚠️ **ファイル名は記録ではない。** どのショットの出力かは、フォルダが持つ。
⚠️ **フォルダ名は仕様ファイルと同じで、連番の順に並ぶ。**
