## 5. 基準が通った後（API）

1. 同じ條件のショットを、基準畫像を添えて `images/edits` で燒く。
2. **Negative はプロンプトに畳む**（API に専用の欄が無い）。
3. **16:9 は API の `size` 次第。** 鍵が入ったら1枚で確かめる。3:2 で戻れば基準に寄せて切る。
4. 私が檢品し、外れなら直して再生成（1本3回まで）。
5. 通った候補をテイクに記錄（`adopted` は書かない）。**採用は著者。**
