# `hitosara/` — 直到一盘做好

从面粉、水、盐与时间开始，直到面包成为一盘。**10个镜头。**
一部与 Ukebi 完全独立的作品，**放在这里，是为了把这个基盘所读的一切都展示出来。**

> **故事，变成一连串的镜头。**

---

# ⚠️ 投入生成器的只有 §18

`specs/video/shot-XX-*.md` 持有 §1–20。**其中交给模型的只有 §18。**

| | | |
|---|---|---|
| **§1–17** | **底稿。** §18 的7个槽位是从这里导出的 | **不投入** |
| **§18** | `# 18. WAN 3.0 PROMPT MAPPING` — **7个槽位。是英语** | **投入** |
| **§19–20** | 我们这一侧的记录（§19 是解决值，§20 是反省与下一次生成） | **不投入** |

**范围**: 从 `# 18. WAN 3.0 PROMPT MAPPING` 到 `## Style Motion` 的正文末尾。

⚠️ **7个槽位要分开投入。** `Master` / `Visual` / `Motion` / `Camera` / `Audio` /
`Negative` / `Style Motion`。「**彼此分离本身就是要点**，所以不要混在一起」
（`references/video-spec.md`）。
⚠️ **投入目标只有一个栏位时，就把它们接起来。**
⚠️ **把那个镜头的时长放进 `{DURATION}`**（本作品里是 2s〜8s）。

### ⚠️ 不得投入 §19、§20

§19 是列出了 `Instance ID` 与 `Generation Date` 的**我们这一侧的台账**。
§20 里写着「**这次生成应当确认的忧虑**」——⚠️ 例如
**「`Lettering may appear on the sacks.`」**。**这等于是把失败的名字，放进提示词里。**

⚠️ **§12 的标题里也有日语**（`## MUST NOT (prohibitions for this one shot, …)`）。
**§18 里没有日语**——不要混。**交出去的是英文字符串。**

---

# ⚠️ 图像的规格没有 §18

`specs/image/shot-XX-*.md` 不持有 §1–20。**一个节里的两个段落**是正典。

| | |
|---|---|
| **第1段** | **`Prompt`** — **原样投入 `chatgpt-image-2.5`** |
| **第2段** | **`Negative`** — 与第1段之间**由1个空行**连接 |

⚠️ **那个空行就那样留在记录里**（决定A）。**连着空行一起投入。**
⚠️ **不要保留接好的字符串的副本**——**副本会相互矛盾。**
⚠️ **不持有 §1–20 是种类的问题，不是模式的问题。** 每个镜头都有两条路径。

---

# ⚠️ 运行的顺序

**10张图像 → 全部看过 → 10条视频。**
如果第一帧与预期不符，在它上面再堆10条视频，就是**10倍的浪费。**

- **图像是作为附件（参照图像）交给视频的。不是第一帧。**
  若当成第一帧，**那个镜头的变化就不会在画面上发生**
  ——变化已经在图像里完成了。
- **生成物的放置处是 `media/`。** 基盘不读这里（`media/README.md`）。
- **回来的东西要记录到 `takes/`。放下过，不等于记录过。**
- ⚠️ **`takes/` 由 `L25` 读。`media/` 谁都不读。**
  所以**实物与记录的出入，机器不会报警**——`L25` 会在注里作为文章报告。
  **`media/` 里存在却没有记录的，不去找就找不到。**
  ⚠️ **反方向也存在**——**记录所声称的文件，已经不在了**。
  `file` 是声称而不是证明，所以**即使消失，机器也保持沉默。**

# 构成

| | |
|---|---|
| `bible.yaml` | 世界、根本律、视觉语言。**样式是 `luminous-anime`**（卡持有 `Motion character`） |
| `ledger.yaml` | 台账是**一个**（连续性＋开示——人物、地点、道具，窑打开的位置、面包裂开的位置） |
| `shots/` | 10个。`role` / `mode` / `beats` / `reference_set` / `attached` / `disclosure_state` / `motion` |
| `specs/video/` | 10个。持有 §1–20。**投入的只有 §18** |
| `specs/image/` | 10个。不持有 §1–20。**两个段落**是正典 |
| `media/` | 生成物的放置处。**基盘不读。** ⚠️ **实物与记录的差异，机器不会报警** |
| `takes/` | 镜次的记录。**只放下来不算记录。** `L25` 会读 |
| `renders/` | **编辑做出来的东西（作品）。** 标本在 `media/`，作品在这里——⚠️ **不要混** |
| `timeline/` | 编辑的记录。**尚未被打开** |

⚠️ **检查只有事前验证。** `python3 engine/ledger/check.py projects/hitosara`。
**违规0件不是「正确」**——要读注，以及没有被检查到的范围。
