# `takes/` — この作品はまだ1本も生成していない

**このディレクトリは意図的に空である。**

テイクの記録は `*.yaml` である（`schemas/take.schema.json`）。1本も無い。

⚠️ **これを「0件だから正しい」と読んではならない。**
`check.py` はこのディレクトリについて、こう報告する——

> `takes/` は在るが、**テイクの記録が1本も無い**——生成は一度も走っていない。
> 「テイク0件」は「違反0件」ではない。**選別の検査が空である。**

**空を OK と言わない。** このディレクトリが空であることは、
**選別の層が一度も動いていない**という報告であり、合格ではない。

⚠️ **`.gitkeep` ではなく、この文を置いてある。** 空のディレクトリは
clone で消える——**消えれば、「無い」と「空である」の区別も消える。**
`check.py` はその2つを別の符号で報告する（「`takes/` が無い」と
「`takes/` は在るが1本も無い」）。**区別を残すために、中身のある空を置く。**

⚠️ **`*.md` は読まれない。** `Project.__init__` は `*.y*ml` だけを読む。
だからこの文はテイクとして数えられない——**数えられては困る。**
