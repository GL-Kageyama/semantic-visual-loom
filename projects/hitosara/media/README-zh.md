# `media/` — 作者放下生成物的放置处

**这里基盘不读。** 它是放置生成物（图像、视频）的地方，
`check.py` 与 `semantic.py` 都不打开这个目录。

## ⚠️ 图像与视频都放在**这里**

⚠️ **不要把视频放进 `takes/`。** `takes/` 是**记录**（`*.yaml`）的地方——
**不要把物与记录混在同一个地方。** 实物放 `media/`，记录放 `takes/`。

⚠️ **不要把编辑过的东西（接起来的东西）放在这里。** 这里是**标本**的地方，
不是**作品**的地方——接起来的东西是 `../renders/`。
⚠️ **一旦混了，标本的缺失与作品的存在就再也分辨不出来**——
**长着「没有记录的镜次」那张脸的作品**，会在这里排成一列。

⚠️ **`.mp4` 与 `.png` 由 Git LFS 追踪**（`.gitattributes`）。

```gitattributes
*.mp4 filter=lfs diff=lfs merge=lfs -text
*.png filter=lfs diff=lfs merge=lfs -text
```

⚠️ **只是放下，并不会成为 LFS。** 只有 `git add` 之后，它才会变成
**133字节的指针**，实体进入 `.git/lfs/objects/`。
**一直 untracked 的文件，在仓库里不存在**——
**clone 的人看不到，消失了也没有人察觉。**

⚠️ **实体在 push 的时候一起上去。** 如果只有指针上去，
**clone 的人拿不到视频。**

⚠️ **`git lfs ls-files` 的第2列，不是手头实体的有无。**
`*` 指「完整的对象」，`-` 指「**LFS 指针**」（`git lfs ls-files --help`）——
也就是说，它是**磁盘上的副本是指针（或不存在）**这一点的标记，
**并不说明 `.git/lfs/objects/` 里有没有实体。**
⚠️ **实际上，有3个文件是 `-` 却存在实体**（`2__` `5__` `6__` 的旧名——
**对象在手头，只有磁盘上的副本没有了**）。
**要确认实体，就打开 `.git/lfs/objects/<oid 的前1〜2个字>/<3〜4个字>/<oid>`。**

⚠️ **指针无法解析的状态，实际发生过**（并且曾被记录过一次）。
`02__20260913-….mp4` 是作为**133字节的指针**提交的，
**那个文件从工作树里消失了。**
⚠️ **但它的实体在手头的 LFS 里**——`0c119d5c…`（10,456,290 字节）。
ffprobe 把它读作 `1920x1080 / 60 frames / 2.000s`。
⚠️ **写「实体哪里都没有」是错的**（`HISTORY.md` 的 0.17.1）。
⚠️ **在不在远端，从这里测不出来。**

⚠️ **文件名以 `NN__` 开头**（`01__` … `10__`）。名字是拉出记录的线索。
⚠️ **它的读法——开头数字是镜头编号——是由作者
用镜头编号指了其中一个文件而确认的**（`6__78bbaadd-….mp4` = 镜头6，2026-09-13）。
**这不是推测，而是由1点实测支撑的读法。**
⚠️ **这个拼写会动。** 不要把现在存在的名字数出来写进这段文字——**写下来就会矛盾。**

⚠️ **生成物是很大的二进制。** 放不放由作者决定。
**这个仓库不执行生成**（环境里没有 API 密钥）。
作者用手跑，把回来的东西在 `takes/` 里**记录**——
**放下过，不等于记录过。**

⚠️ **这个目录里有东西，不是任何一种报告。**
`takes/` 的空会被报告。**这边的空、这边的充实，都不会被报告。**
**文件存在，不等于那个镜头通过了。**

## ⚠️ `L25` 守着这个宣言

`L25` **既不打开、也不 `stat`** `take.file` 所声称的文件——
所以**即使这个目录的内容与 `takes/` 的记录矛盾，机器也不会报警。**

⚠️ **那个出入有两个方向。** **① 这里存在，却没有记录。**
**② 记录声称着，这里却没有。**——**②真的发生过。**
声称 `02__20260913-….mp4` 的镜次在 `takes/` 里，但**那个文件已经不在了。**
`6__78bbaadd-….mp4` 也一样——**声称它的镜次在，文件不在。**
⚠️ **两者都是，实体在手头的 LFS 里**——**消失的是名字，不是物。**
⚠️ **所以镜次的数量和这里的 mp4 数量不一致。** **两个方向，机器都不会报警。**
⚠️ **不要把数量写进这段文字。** 数量会动——**写下来就会矛盾。**

⚠️ **要用检查堵上这个洞，就得先改变这个宣言（「基盘不打开这里」）。**
**堵不堵尚未决定**——让 `media/` 可读，记录与实物的出入就会由机器报警。
但那时，**基盘就成了一个窥视二进制放置处的东西。**

⚠️ **`*.md` 不会被读。** 所以这段文字不会被算作素材。
