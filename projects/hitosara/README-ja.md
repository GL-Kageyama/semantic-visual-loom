# `hitosara/` — 一皿ができるまで

粉と水と塩と時間から、パンが一皿になるまで。**10ショット。**
受け火から完全に独立した作品で、**この基盤が何を読むかを全部見せるために置いてある。**

> **物語が、連続したショットの列になる。**

---

# ⚠️ 生成器へ投入するのは §18 だけである

`specs/video/shot-XX-*.md` は §1–20 を持つ。**そのうちモデルへ渡すのは §18 だけである。**

| | | |
|---|---|---|
| **§1–17** | **下敷き。** §18 の7スロットはここから導かれる | **投入しない** |
| **§18** | `# 18. WAN 3.0 PROMPT MAPPING` — **7スロット。英語である** | **投入する** |
| **§19–20** | 我々の側の記録（§19 は解決値、§20 は反省と次の生成） | **投入しない** |

**範囲**: `# 18. WAN 3.0 PROMPT MAPPING` から `## Style Motion` の本文末まで。

⚠️ **7スロットは分けて入れる。** `Master` / `Visual` / `Motion` / `Camera` / `Audio` /
`Negative` / `Style Motion`。「**分離されていること自体が要点**なので、混ぜない」
（`references/formats/video-spec.md`）。
⚠️ **投入先が1つの欄しか持たない場合は繋ぐ。**
⚠️ **`{DURATION}` には、そのショットの尺を入れる**（この作品では 2s〜8s）。

### ⚠️ §19・§20 を入れてはならない

§19 は `Instance ID` や `Generation Date` を並べた**我々の帳簿**である。
§20 には「**この生成で確かめるべき危惧**」が書いてある——⚠️ たとえば
**「`Lettering may appear on the sacks.`」**。**失敗の名前を、プロンプトの中に入れることになる。**

⚠️ **§12 の見出しにも日本語が在る**（`## MUST NOT（この1本の禁止・…）`）。
**§18 の中に日本語は無い**——混ぜない。**渡す文字列は英語である。**

---

# ⚠️ 画像の仕様は §18 を持たない

`specs/image/shot-XX-*.md` は §1–20 を持たない。**1つの節の中の2段落**が正典である。

| | |
|---|---|
| **1段落目** | **`Prompt`** — **そのまま `chatgpt-image-2.5` へ投入する** |
| **2段落目** | **`Negative`** — 1段落目と**空行1つ**で繋がっている |

⚠️ **その空行は、記録の中にそのまま在る**（決定A）。**空行ごと投入する。**
⚠️ **繋いだ文字列の写しは置かない**——**写しは食い違う。**
⚠️ **§1–20 を持たないのは種類の話であって、モードの話ではない。** 全ショットが2つの経路を持つ。

---

# ⚠️ 回す順番

**画像10枚 → 全部見る → 動画10本。**
最初のコマが狙いと違えば、その上に動画を10本積むのは**10倍の無駄**になる。

- **画像は、動画へ添付（参照画像）として渡る。最初のコマではない。**
  最初のコマにすると、**そのショットの変化が画面上で起きなくなる**
  ——変化はもう画像の中で済んでいる。
- **生成物の置き場は `media/`。** 基盤はここを読まない（`media/README.md`）。
- **戻ってきたものは `takes/` に記録する。置いたことは、記録したことではない。**
- ⚠️ **`takes/` は `L25` が読む。`media/` は誰も読まない。**
  だから**実物と記録の食い違いは、機械が鳴らさない**——`L25` が註で文章として報告する。
  **`media/` に在るのに記録が無いものは、探さないと見つからない。**
  ⚠️ **逆向きもある**——**記録が名乗るファイルが、もう無い**場合である。
  `file` は名乗りであって証明ではないので、**消えても機械は黙っている。**

# 構成

| | |
|---|---|
| `bible.yaml` | 世界・根本律・視覚言語。**様式は `luminous-anime`**（カードが `Motion character` を持つ） |
| `ledger.yaml` | 台帳は**ひとつ**（連続性＋開示——人物・場所・道具、窯が開く位置、パンが割れる位置） |
| `shots/` | 10本。`role` / `mode` / `beats` / `reference_set` / `attached` / `disclosure_state` / `motion` |
| `specs/video/` | 10本。§1–20 を持つ。**投入するのは §18 だけ** |
| `specs/image/` | 10本。§1–20 を持たない。**2段落**が正典 |
| `media/` | 生成物の置き場。**基盤は読まない。** ⚠️ **実物と記録の差は、機械が鳴らさない** |
| `takes/` | テイクの記録。**置くだけでは記録にならない。** `L25` が読む |
| `renders/` | **編集で出来たもの（作品）。** 標本は `media/`、作品はここ——⚠️ **混ぜない** |
| `timeline/` | 編集の記録。**まだ開かれていない** |

⚠️ **検査は事前検証だけである。** `python3 engine/ledger/check.py projects/hitosara`。
**違反0件は「正しい」ではない**——註と、検査されていない範囲を読むこと。
